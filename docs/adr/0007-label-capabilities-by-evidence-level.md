# Label capabilities by evidence level

Every operator-facing capability and thesis claim will carry an evidence-backed Capability Level instead of being called supported merely because code exists. Live ingestion, health, policy evaluation, and durable Incident workflow target `OPERATIONALLY_DEMONSTRATED`; fusion, auction verification, multimodal correlation, and guarded explanation remain `RESEARCH_PROTOTYPE`; VLM context, semantic retrieval, bandit adaptation, and learned priority remain `EXPERIMENTAL`; unsafe staged types such as violence, gunshot, and glass breaking remain `PREPARED_REPLAY_ONLY`.

## Consequences

The live home demonstration excludes claims for fire, weapons, identity recognition, and general open-world anomaly detection. Optional retrieval reports its active Search Level and degrades to deterministic lexical or metadata search when models are unavailable. Three private staged repetitions are deployment checks reported as raw outcomes, not a statistically reliable benchmark.
