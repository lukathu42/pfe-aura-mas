# CUHK Avenue Media

This directory is the local extraction point for the official CUHK Avenue
video and ground-truth archives. The media is ignored because the archive is
large and is distributed separately for academic research.

Download links and the manifest-generation command are documented in
[`docs/avenue-scenario-pack.md`](../../docs/avenue-scenario-pack.md). The
tracked `scenarios/avenue_*.json` files are generated from this directory and
must not be used without first verifying that the local media is present.
